# Production visual references

These 42 PNGs were captured from [the live product](https://once-upon-a-bitcoin.vercel.app/) with the application bundle verified against approved baseline [b7d9835](https://github.com/tricialinewberg/once-upon-a-bitcoin/commit/b7d9835372ec7275dcd2b3b4273ff65b8476650f). Browser viewports were 390 × 844 and 1440 × 900 CSS px, Portuguese, 1× device pixel ratio, with reduced motion for repeatable states. Browser emulation was used. Component crops retain their original rendered dimensions and may be narrower than the viewport. Homepage frames are viewport captures.

Each image represents an authentic production state. Put the screenshot on a locked reference layer and reconstruct the interface as editable elements.
