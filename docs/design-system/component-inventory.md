# Component inventory

Source names are relative to `src/`. Dimensions, typography, spacing, backgrounds, borders and radii for sampled rendered selectors are in [tokens.json](tokens.json) under `implemented.computed`. Authored selectors and sources are indexed under `authored`. Mobile means below the component’s indicated threshold, with 390px used as the sample. Default native keyboard actions apply to links, buttons, radios, checkboxes, ranges and details. Focus-visible rules and motion preferences are covered in the companion pages.

## Implemented state sets

The inventory distinguishes thirteen major state or configuration families: menu open/closed; indexed current route; language PT/EN; directional destinations; native disclosure open/closed; responsive benefits; five milestone selections; coin/hero visual lifecycle; converter/fee; exchange/personal custody; three scenario kinds with semantic outcomes; receive/send with step boundaries; and checklist progress. Hover, focus and active coexist with those families only where the corresponding selectors/native controls implement them. Loading skeletons, disabled links, complex menu navigation and table sorting are potential later components, with no implemented variant here.
