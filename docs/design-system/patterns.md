# Educational patterns

| Pattern | Implemented behavior and dependencies |
|---|---|
| Progressive reading | Home presents linked learning intentions and an optional index. Chapter header, route destination links and persistent menu allow non-linear access. Scroll progress is based on the page height and is distinct from checklist completion. |
| Compare alternatives | Benefits reveal, custody choice, wallet and balance pairs and backup guidance juxtapose choices. Only controls with state expose pressed/expanded semantics. Static comparison tables remain readable without interaction. |
| Visual explanation | Network assets and animated peers accompany prose. Timeline selects one historical year and shows text plus alternate art. Supply pairs tabular numerical emphasis with a medallion. |
| Safe simulation | Calculator displays hypothetical sats/BTC or a fee example, with input constraints and no financial API. Transfer practice uses fictional instructions and an illustrative address. Recovery card contains masked slots and requires no secret. No wallet connection or transaction is involved. |
| Immediate learning feedback | Choice → visible result → explanation. Selected answer receives semantic styling plus a textual status. Chapter VI scam response uses the same Scenario component with route-local styling. |
| Guided steps | Wallet setup uses ordered steps. Interactive practice switches receive/send modes and resets to step one; previous is disabled at the start and restart is offered at the end. |
| Information disclosure | Journey index, sources and FAQ use native details/summary. Chapter I benefits uses separate mobile and desktop presentation of the same content. |
| Readiness and reflection | Checklist is optional and session scoped. Completion message appears when all ten entries are checked. FAQ uses native disclosure; final navigation can return to the journey. |
| Bilingual continuity | Paired content and locale formatting are stored in code and master content. The route stays the same on language change, the app attempts to preserve reading position, and English and Portuguese share canonical URLs. Activity state uses in-document persistence, checklist uses session storage and language uses local storage. |

The activity pattern inventory describes implemented behavior. No research, success-rate or financial outcome claim is inferred.
