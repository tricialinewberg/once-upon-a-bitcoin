# Once Upon a Bitcoin

### Knowledge is the key.

An interactive, bilingual educational experience designed to make Bitcoin and self-custody more accessible, understandable, and approachable.

**Designed & Developed by Trícia Linewberg**

## About the project

Learning about Bitcoin can be overwhelming. Technical terminology, complex interfaces, fragmented information, and security concerns often create unnecessary barriers for beginners.

Once Upon a Bitcoin was created to help remove those barriers through an intentional combination of education, human-centered design, visual storytelling, and interactive learning.

The project is particularly motivated by the challenges faced by women entering the Bitcoin ecosystem, while remaining accessible to anyone interested in learning.

## The design challenge

What does someone need to understand, visualize, and be able to do to feel confident taking control of their own bitcoin?

The experience was developed around three fundamental pillars:

- **Understand:** Make complex concepts accessible.
- **Visualize:** Transform abstract information into meaningful visual experiences.
- **Practice:** Build confidence through safe educational simulations.

## The learning journey

The website is organized into seven independent chapters:

| Chapter | Topic |
|---|---|
| I | A new way to understand money |
| II | The secret of 21 million |
| III | The power of your own keys |
| IV | The 12 secret words |
| V | Your first wallet |
| VI | Protecting your Bitcoin |
| VII | The next chapter is yours |

Each chapter combines educational content, visual hierarchy, meaningful interactions, and practical guidance.

## Key features

- Seven independently navigable educational chapters.
- Portuguese and English language support.
- Mobile-first responsive design.
- Interactive Bitcoin history timeline.
- Satoshi unit converter.
- Animated decentralized network visualization.
- Interactive custody comparison.
- Recovery phrase and backup education.
- Transaction and fee simulations.
- Scam-awareness activities.
- Self-custody readiness checklist.
- Custom illustrations and 3D motion.
- Accessible interaction states and reduced-motion considerations.

## Design approach

The project combines UX/UI Design, Product Design, educational design, and frontend development.

Design decisions were guided by:

- Information architecture and progressive learning.
- Visual hierarchy and cognitive load reduction.
- Consistency through reusable design components.
- Meaningful motion and microinteractions.
- Accessibility and responsive behavior.
- Clear educational feedback.
- User autonomy, privacy, and security.

The visual identity uses Bitcoin Orange, warm neutral surfaces, charcoal tones, Manrope, and Inter.

## Getting started

Clone the repository:

`git clone https://github.com/tricialinewberg/once-upon-a-bitcoin.git`

Navigate to the project directory:

`cd once-upon-a-bitcoin`

Install dependencies:

`npm install`

Start the development server:

`npm run dev`

Create the production build:

`npm run build`
